The Phoenix Puppet is one of the many projects I have worked on for the Center of Holistic Integration at City Tech. This interactive project features an animated phoenix that responds to mouse movement, along with an online rig that allows users to control the puppet directly. To activate Puppet Mode, simply press P.

## Phoenix Puppet Controls

| Command | Mode | Action |
|---|---|---|
| **P** | Global | Toggle **Puppet Mode** on/off |
| **C** | Global | Toggle **Camera Mode** on/off. The Phoenix follows movement detected by the webcam instead of the mouse |
| **W** | Puppet | Fly upward |
| **A** | Puppet | Fly left |
| **S** | Puppet | Fly downward |
| **D** | Puppet | Fly right |
| **R** | Puppet | Reverse the Phoenix's direction |
| **I** | Puppet | Toggle **Idle / Perch Pose** |
| **0** | Puppet | Gradually vanish / reappear |
| **1** | Puppet | Dramatic entrance from the upper-left |
| **2** | Puppet | Toggle **Flame Mode** with pulsating fire aura |
| **4** | Puppet | Toggle strong white glow |
| **5** | Puppet | Dramatic exit toward the upper-right |
| **9** | Puppet | Show / hide the bottom status text |
| **B** | Puppet | Toggle fiery background / transparent background |
| **M** | Puppet | Show / hide the Puppet Mode command box |

## Normal Mode Controls

| Control | Action |
|---|---|
| **Mouse Movement** | Phoenix flies toward and follows the mouse |
| **Touch / Drag** | Phoenix follows touch movement on supported mobile devices |
| **10 Seconds Inactive** | Phoenix returns to the center and enters its idle / perch pose |
| **Mouse / Touch Movement While Idle** | Wakes the Phoenix and resumes following |
| **C** | Switches from mouse control to webcam movement tracking |

## Camera Mode

| Camera Action | Phoenix Response |
|---|---|
| **Move around in camera** | Phoenix follows the detected movement |
| **Move after Phoenix becomes idle** | Phoenix wakes up and resumes following movement |
| **C** | Exit Camera Mode and restore normal mouse control |
